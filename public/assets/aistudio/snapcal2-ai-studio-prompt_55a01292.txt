Build a mobile-first, installable-feeling web app called "SnapCal" using React + TypeScript + Tailwind CSS, with components in the style of shadcn/ui (Radix primitives), lucide-react icons, recharts for charts, sonner for toasts and date-fns. Follow every detail below exactly. Do not add extra features, pages, colors or sections, and do not change any wording.

========================================
1. WHAT THE APP IS
========================================
SnapCal estimates calories, macros, micronutrients and a health score from a photo of a meal using the Gemini API. The user can edit portions, rename or remove items, add missed foods, and re-analyze with extra context. Meals are saved to a diary. The app has four pages: Snap (/), Diary (/diary), Insights (/insights), Goals (/goals). It has three languages (Arabic, English, French), one warm dark theme only, and a footer credit.

Page titles / meta:
- /  → "SnapCal — Snap a photo, know your calories" (description: "Snap a photo of any meal and SnapCal's AI estimates calories, protein, carbs, fat and more in seconds.")
- /diary → "Diary — SnapCal" (description: "Your saved meals, grouped by day, with totals against your goals.")
- /insights → "Insights — SnapCal" (description: "Daily calorie and protein trends against your goals.")
- /goals → "Goals — SnapCal" (description: "Set your daily calorie and protein targets.")
Unknown route → 404 page: centered, "404" (text-7xl bold), then t("notFound.title") as h2 (text-xl semibold), t("notFound.text") (text-sm muted), and a primary button t("notFound.home") linking to "/".
Global error boundary: centered title t("error.title"), text t("err.server"), buttons t("error.retry") (primary) and t("notFound.home") (outlined link to "/").

3. LANGUAGES / i18n / RTL
========================================
Languages: ar (العربية), en (English), fr (Français). Native names are shown in the switcher.
- Default: stored choice in localStorage key "snapcal.lang", else the first browser language whose base code (before "-") is ar/en/fr, else English.
- Changing language stores it and sets <html lang> and <html dir> ("rtl" for Arabic, "ltr" otherwise). The whole layout must mirror correctly in RTL: use logical Tailwind classes (ms-, me-, ps-, text-start, text-end), and wrap the app in a Radix DirectionProvider.
- All dates and numbers are formatted with Intl using locale `${lang}-u-nu-latn` so digits are ALWAYS Latin (0-9), even in Arabic.
- Translation function t(key, vars): looks up the current language, falls back to English, then to the key; replaces {name} placeholders.
- The footer is ALWAYS dir="ltr".

9. CORE LOGIC (EXACT)
========================================
Nutrition model:
- Nutrient keys: calories, protein_g, carbs_g, fat_g, fiber_g, sugar_g, sodium_mg, saturated_fat_g.
- FoodItem = { id (random 8-char base36), name, grams, portion_description, per_gram: {all 8 nutrients PER GRAM} }.
- Build an item from AI values: grams = max(1, round(grams if it is a positive finite number, else 100)); per_gram[k] = (value if positive finite else 0) / grams; name trimmed or "Food item"; portion_description trimmed or "{grams} g".
- An item's nutrients = per_gram × current grams. TOTALS ARE ALWAYS COMPUTED FROM THE ITEMS, never trusted from the model.
- Saved meal columns from totals: calories rounded to integer; protein, carbs, fat, fiber, sugar rounded to 1 decimal; sodium_mg integer.

Goals logic:
- Goal types: cut, maintain, bulk. Defaults: calories 2000, protein 100 g, goal_type "maintain".
- Activity factors: sedentary 1.2, light 1.375, moderate 1.55, active 1.725, very 1.9.
- Calorie factor by goal: cut 0.8, maintain 1.0, bulk 1.1. Protein g per kg by goal: cut 2.0, maintain 1.6, bulk 1.8.
- Cut calorie floor: male 1500, female 1200 (use min(floor, maintenance)); if the cut result is below the floor, raise it to the floor and show the floor note.
- BMR (Mifflin–St Jeor) = 10×kg + 6.25×cm − 5×age + (male +5 / female −161). maintenance = round-to-nearest-10(BMR × activity). calories = round-to-nearest-10(maintenance × goal factor). protein_g = round(kg × protein-per-kg).
- calorieStatus(goal, consumed, target): diff = round(consumed − target), abs = |diff|.
  cut: diff > 0 → state "over", flagged; else state = "met" if abs ≤ 5% of target, otherwise "left"; not flagged.
  bulk: diff ≥ 0 → "met"; else "short", flagged.
  maintain: abs ≤ 10% of target → "met"; diff > 0 → "over", flagged; else "left".
  Text keys: status.over / status.short / status.left / status.met (diary) and status.avgOver / avgShort / avgLeft / avgMet (insights).
